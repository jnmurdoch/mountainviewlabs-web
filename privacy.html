Notifier Privacy Policy

Last updated: October 9, 2026

Overview

Notifier is a personal event tracking and reminder application developed by Mountainview Labs.

Information We Use

Notifier stores information about events selected for tracking, associated dates, notification preferences, and delivery status.

With user authorization, Notifier uses the Google Calendar API to create, retrieve, update, and manage calendar entries associated with tracked events.

How Information Is Used

Google Calendar access is used exclusively to provide calendar integration for Notifier's reminder functionality.

Google user data is not used for advertising, marketing, or training AI models.

Storage and Security

Notifier operates on privately managed infrastructure. Application records and Google authorization credentials are stored within that environment, with access restricted to the application operator.

Information Sharing

Notifier does not sell Google user data or share Google Calendar information with advertisers or data brokers.

Notifier uses Google Calendar services to perform authorized calendar operations and an SMS provider to deliver reminder messages.

Data Retention and Access Revocation

Application records are retained for operational use until removed by the application operator. Google Calendar access can be revoked through the user's Google Account settings.

Revoking access prevents further authorized Calendar API operations but does not automatically delete application records or previously created calendar entries.

Google API Limited Use

Notifier's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

For privacy inquiries, contact the application operator using the support contact provided on Notifier's Google OAuth consent screen.
